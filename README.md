## Описание проекта

Проект представляет собой REST-приложение на Java с использованием Spring Framework, реализующее игру «Крестики-нолики» против компьютера. Приложение поддерживает одновременное ведение нескольких игр, хранение их состояния в памяти, проверку корректности ходов и вычисление оптимального ответа компьютера с помощью алгоритма Minimax. Архитектура проекта построена по многослойному принципу с разделением на web, domain, datasource и di.

---

## Результат

В результате разработано многослойное REST-приложение, которое:

- реализует игру «Крестики-нолики» против компьютера;
- вычисляет оптимальный ход с использованием алгоритма Minimax;
- проверяет корректность игровых состояний и определяет окончание партии;
- поддерживает одновременную работу с несколькими независимыми играми;
- хранит игровые состояния в потокобезопасном хранилище в памяти;
- использует Spring для реализации REST API и управления зависимостями;
- разделяет бизнес-логику, работу с данными и HTTP-интерфейс на независимые слои.

# Системные требования

Для запуска проекта необходимо установить:

- **JDK 18** или выше;
- **Git** (для клонирования репозитория);
- современный веб-браузер (Google Chrome, Mozilla Firefox, Microsoft Edge и др.).

> Отдельная установка Gradle **не требуется**, поскольку проект использует **Gradle Wrapper** (`gradlew` / `gradlew.bat`).

# Запуск проекта

После запуска Spring Boot автоматически поднимет встроенный веб-сервер.

По умолчанию приложение будет доступно по адресу:

```
http://localhost:8080
```

Фронтенд уже входит в состав проекта и расположен в папке `src/main/resources/static`, поэтому никаких дополнительных действий по его сборке или запуску выполнять не требуется.

## Windows

### Способ 1. IntelliJ IDEA

1. Клонируйте репозиторий:

```bash
git clone <URL_репозитория>
```

2. Откройте проект в IntelliJ IDEA.

3. Дождитесь загрузки Gradle-зависимостей.

4. Запустите класс

```
Application.java
```

или используйте кнопку **Run**.

После запуска откройте браузер:

```
http://localhost:8080
```

---

### Способ 2. Gradle Wrapper

Откройте PowerShell или Command Prompt в каталоге проекта.

Запустите приложение:

```bash
gradlew.bat bootRun
```

или сначала соберите проект:

```bash
gradlew.bat build
```

после чего выполните:

```bash
java -jar build/libs/*.jar
```

# Использование приложения

После запуска приложения откройте в браузере:

```
http://localhost:8080
```

Откроется игровое поле, где можно сразу начать новую игру против компьютера.

Игровой процесс полностью выполняется через веб-интерфейс:

- нажмите **New Game** для создания новой партии;
- сделайте ход, нажав на свободную клетку;
- компьютер автоматически выполнит ответный ход;
- после окончания партии можно начать новую игру без перезапуска приложения.
